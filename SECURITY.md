# Security Policy

## Supported versions

Security fixes go into the latest release line of rabl. Please check that the problem occurs on the latest release.

## Reporting a vulnerability

Please report vulnerabilities privately, through GitHub's private vulnerability reporting: on the repository's
[Security tab](https://github.com/nesquena/rabl/security), choose "Report a vulnerability". Don't open a public issue or
pull request for a vulnerability.

Include the rabl version, the steps to reproduce the problem and its impact. The discussion continues in the report
until a fix is released.
